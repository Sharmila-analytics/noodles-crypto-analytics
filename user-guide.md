# User Guide: Noodles Crypto Dashboards

## Opening a report
1. Open the required `.pbix` file in Power BI Desktop.
2. Confirm the configured data source is available before refreshing.
3. Select **Home → Refresh** only when the source is available.
4. Check all pages for error messages and missing visuals.

## Executive Dashboard
Use KPI cards for summary values, the currency table for comparisons, the Top N selector for rankings, the date slicer for a period, and the platform donut chart for platform engagement share. Hover over visuals to view tooltips.

## Time Series Analysis
Use the date slicer to focus on a period. Hover over points to inspect values. Check unusual spikes against source data before drawing conclusions.

## Platform Analysis
Compare total engagement and average engagement score by platform. Select a platform in a visual to cross-filter other visuals where interactions are enabled.

## Currency Deep Dive
Use the currency selector or right-click a currency in the Executive Dashboard and select **Drill through → Currency Deep Dive** when available. Review the engagement-score trend and platform breakdown; use the back button to return.

## Bookmarks and filters
Bookmarks such as **Overview View** and **Platform Comparison** switch between saved report states. Clear selections or restore the default bookmark to return to a broader view.

## Exporting and sharing
Export and share only as permitted by your organization and assignment. Power BI Service sharing requires suitable licensing, permissions and configured data access; do not assume the report is published or scheduled refresh is active unless tested.

## Interpreting metrics
Values depend on the selected date range, currency, platform and other filters. Correlation does not prove causation. Verify unexpected results against the underlying data.
